# Dental3D Studio — Alpha

Dental3D Studio is a native desktop application built with Python, PySide6, and PyVista/VTK for organizing, visualizing, and analyzing 3D dental surface scans (STL and PLY) alongside experimental orthodontic retainer modeling.

---

## Overview

Dental3D Studio provides a clean, unified desktop environment with two dedicated workspaces:

- **Scan Simulation Workspace**: High-performance interactive 3D viewport for inspecting single and dual-arch dental scans, with camera navigation controls (`Ctrl + Drag` to rotate, `Shift + Drag` to pan), Quick View mode, scan import, lighting controls, illustrative previews, and an independent pop-out 3D viewer window.
- **Cases & Treatment Workspace**: Structured case management, pseudonymous patient referencing, persistent treatment stages (Initial, Intermediate, Final), and preliminary Essix-style retainer shell generation and geometric comparison.

---

## What It Can Do

- **3D Mesh Visualization**: Render 3D dental arches with smooth shading, customizable studio lighting, directional orientation indicators, and ground shadows.
- **Dual-Arch Inspection**: View upper and lower jaws individually or simultaneously with independent visibility toggles and display-only arch separation.
- **Quick View Mode**: Inspect STL/PLY meshes immediately without needing to open or modify a case.
- **Pop-out 3D Viewport**: Launch an independent, enlarged viewer window ideal for multi-monitor inspection.
- **Case & Treatment Management**: Create, save, and reopen cases locally, with scan metadata, source references and recorded analysis provenance.
- **Treatment Stage Tracking**: Organize scans into Initial, Intermediate, and Final stages to track alignment progress over time.
- **Mesh Validation**: Verify mesh integrity (manifold geometry, non-zero extent, finite coordinates, and degenerate triangle detection).
- **Geometric Mesh Analysis**: Calculate vertex/face counts, bounding dimensions, surface area, and watertight manifold volume.
- **Surface Distance Comparison**: Compute bidirectional point-to-surface distances between compatible, pre-aligned scans with statistical metrics (mean, RMS, 95th percentile, maximum deviation).
- **Preliminary Retainer Modeling (Experimental)**: Generate Essix-style thin-surface offset shells with configurable thickness and boundary trim, complete with independent opacity and 3D preview.
- **Retainer-to-Scan Comparison**: Perform geometric deviation analysis between generated or imported retainers and anatomical scans.

---

## What It Cannot Do

- **Not a Medical Device**: Dental3D Studio is an engineering prototype for visualization and geometric research. It is **not** certified as a medical device and must **not** be used for clinical diagnosis, active orthodontic treatment planning, or medical decisions.
- **No Automatic Mesh Registration**: The application does not perform automated registration, best-fit alignment, or coordinate frame estimation. Comparative analyses require scans to be co-registered in advance within a shared coordinate system.
- **No Clinical Clearance or Contact Analysis**: Surface distance metrics are raw geometric measurements; they do not measure occlusal contact dynamics, periodontal health, or clinical orthodontic fit.
- **No Direct Manufacturing Readiness**: Retainer shells generated by the offset algorithm are structural references only; they are not certified for direct 3D printing, thermoforming, material retention, or intraoral clinical use.

## What's Included

- **Desktop Application**: Complete source code and assets (`dental3d/`, `app.py`).
- **One-Click Windows Launcher**: `run.bat` for immediate double-click startup.
- **Sample Dental Dataset**: Curated Bits2Bites scan sample pairs (`data/bits2bites_sample/`) for testing and demonstration. The included sample consists of 4 registered upper/lower scan pairs (STL meshes) from the [Bits2Bites dataset](https://ditto.ing.unimore.it/bits2bites/);
- **Automated Test Suite**: Comprehensive unit tests covering case lifecycle, persistence, mesh validation, geometry calculations, and UI event handling (`tests/`).
- **Engineering Tools**: Smoke-testing and dataset auditing utilities (`tools/`).

## How to Run the System

### Option 1: Immediate Launch (Windows)

Double-click **`run.bat`** in the repository root. It automatically detects the virtual environment and starts Dental3D Studio immediately.

### Option 2: Command Line (PowerShell / Terminal)

1. **Set up a Python virtual environment (Python 3.10+ recommended):**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. **Install dependencies:**
   ```powershell
   pip install -r requirements.txt
   ```

3. **Launch the application:**
   ```powershell
   python app.py
   ```

### Running Tests

To run the complete automated test suite:
```powershell
python -m unittest discover -s tests -v
```

To run the real-mesh smoke test on the included sample dataset:
```powershell
python -m tools.smoke_bits2bites_sample .\data\bits2bites_sample
```
Dependencies must be installed before launching.
